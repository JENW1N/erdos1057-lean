## Reproduce

Use Python 3.9+, Git, and the exact Lean toolchain above. The dependency lock is
[the original baseline manifest](../baseline/formal-conjectures/lake-manifest.json),
including Mathlib commit `065356127b1dc0016f66b7283ce0ce2c4055aa55`.

```sh
python3 tools/reproduce_standalone.py --check-sources
python3 tools/reproduce_standalone.py --build-dir ../erdos1057-standalone-check
```

The second command downloads the pinned public dependencies and a Mathlib cache,
then compiles the 189 supplied baseline modules, support file and complete proof
into a new output directory. It runs `standalone/Audit.lean` and Lean's
`leanchecker` replay. The source-check command has passed; the automatic dependency
download path has not been exercised in this publication task.

An existing trusted cache may be reused without reusing custom proof artifacts:

```sh
python3 tools/reproduce_standalone.py \
  --dependency-root /path/to/pinned/formal-conjectures \
  --build-dir ../erdos1057-standalone-check
```

The dependency root must contain `.lake/packages` at every locked commit, with
unchanged tracked sources. All custom proof objects and baseline objects are
still rebuilt. The October 10 check used this cache-reuse method with equivalent
explicit compiler commands, recorded separately. Rebuilding all Mathlib sources
is not claimed.

On macOS the script restricts Lean with `sandbox-exec`: network access is denied,
writes are confined to the new run directory, and user-home contents are denied
except the specified toolchain and read-only dependencies. On other platforms,
run inside a prepared isolated environment and pass `--external-sandbox`; that
flag is a declaration by the caller, not an isolation mechanism. If using Elan,
pass the concrete `lean` binary with `--lean` if necessary. The updated launcher resolves the matching toolchain before creating its isolated HOME.

Logs, commands, source hashes, versions and the final status are written in the
new directory. No `.olean` files are supplied as proof evidence in this repository.
The 500 MB compiled output can be regenerated by the build.

## Version and scope

This is a later source revision than the original October 8 modular proof at
`55fe0f1cd4d8e63b417eb122067ab3e307b39f32`. Of the 320 contributing module-source
hashes, 297 are unchanged and 23 differ. The successful October 9 compile does
not retroactively prove that an identical rebuild of the October 8 revision was
performed. Both versions and their separate evidence remain available.

The direct endpoint remains

```lean
True ↔ Filter.Tendsto
  (fun x => Real.log (Erdos1057.carmichaelCounting x) / Real.log x)
  Filter.atTop (nhds 1)
```

There are no extra mathematical hypotheses on that theorem. The pinned counting
definition uses the standard Carmichael predicate and counts all qualifying
naturals at most each real bound. The [mathematical account](../MATHEMATICAL-ACCOUNT.md)
explains the proof route with links into the preserved earlier modular source;
the exact current file and its audit are authoritative for the current revision.
All four mathematical solver credits, the two Lean formalization credits, and
upstream attribution remain as recorded in [AUTHORS.md](../AUTHORS.md).
